## About Me

SRE and Cloud Operations engineer with **6+ years** supporting 24x7 production environments across banking, contact centre, ERP, and infrastructure domains. I work at the intersection of **reliability engineering, observability, and AI-powered automation** — using tools like Datadog, AWS, and Kubernetes in the day job, and building AI agents with Python and Claude in my own time.

- 🔧 Production support, incident management, and root cause analysis across cloud and on-prem
- ☁️ AWS-hosted and containerised workloads on Kubernetes / OpenShift
- 📊 Datadog and AppDynamics for APM, log analysis, alerting, and dashboards
- 🤖 Building open-source AI tools that automate real engineering workflows
- 📚 Currently pursuing a Post Graduate Program in Cloud Computing
